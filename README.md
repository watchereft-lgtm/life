Клеточный автомат, придуманный математиком **Джоном Хортоном Конвеем** в 1970 году,
в виде интерактивного веб-приложения на [Streamlit](https://streamlit.io).

Никакой графической библиотеки для поля не нужно: сетка рисуется через Pillow,
правило задаётся нотацией B/S, а анимация работает на перезапусках скрипта,
поэтому кнопки и ползунки остаются отзывчивыми во время эволюции.

![Поле после 50 поколений: пушка Госпера и пульсар](docs/preview.png)

*Поле после 50 поколений: слева пушка Госпера выпускает планеры, справа пульсар.
Картинка получена тем же кодом, что рисует приложение ([life_core.py:243](life_core.py#L243)).*

## Возможности

- **Правило в нотации B/S**: `B3/S23` — классика, `B36/S23` — HighLife,
  `B3/S12345` — «День и ночь». Неверная запись не ломает приложение, а показывает ошибку.
- **Поле до 120 × 160** с двумя типами границ: тороидальное (края замкнуты,
  планер уходит за край и возвращается с другой стороны) или с мёртвой границей.
- **Девять готовых фигур**: блок, мигалка, жаба, планер, LWSS, пульсар,
  пушка Госпера, R-пентамино, жёлудь. Ставятся в указанную клетку, в центр
  или заворачиваются через край тора.
- **Свой узор**: ASCII-картинка, где точка или пробел — пусто, любой другой
  символ — живая клетка. Пустые ряды внутри картинки сохраняются.
- **Случайное заполнение** с настраиваемой плотностью.
- **Цвет по возрасту клетки**: зелёный — только что родилась, жёлтый — живёт
  долго, красный — очень старая. По такому полю сразу видно, где кипит жизнь.
- **Метрики и график**: поколение, число живых клеток и история популяции.
- **Управление скоростью** от 1 до 30 шагов в секунду, шаг вручную, пауза.

## Быстрый старт

### Локально

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
streamlit run game_of_life.py
```

Приложение откроется по адресу <http://localhost:8501>.

На Windows есть готовый скрипт — он сам создаст окружение `.venv` и поставит зависимости:

```powershell
.\run.ps1                 # порт 8501
.\run.ps1 -Port 8600      # другой порт
```

На Linux и macOS:

```bash
./run.sh
```

### В Streamlit Community Cloud

1. Загрузите репозиторий на GitHub (файлы уже готовы к этому — см. ниже).
2. На <https://share.streamlit.io> создайте приложение и укажите репозиторий.
3. Главный файл — `game_of_life.py`. Больше ничего настраивать не нужно:
   зависимости берутся из `requirements.txt`, тема — из `.streamlit/config.toml`.

## Как это устроено

**Поле** — массив numpy `uint8`, где 0 означает мёртвую клетку, а положительное
число — возраст живой. Возраст нужен только для раскраски.

**Шаг эволюции** ([life_core.py:79](life_core.py#L79)) считается векторно, без циклов
по клеткам: число соседей получается суммой восьми сдвигов массива через
`np.roll` (тор) или восемью срезами дополненного массива (мёртвая граница).
Правило применяется как таблица переходов: `np.where(alive, survive[n], birth[n])`.
Поэтому поле 120 × 160 считается за миллисекунды.

**Анимация** ([game_of_life.py:186](game_of_life.py#L186)) — главная тонкость Streamlit.
Цикл `while` внутри скрипта заблокировал бы интерфейс: пока скрипт выполняется,
Streamlit не обрабатывает нажатия. Поэтому кадр устроен иначе: скрипт делает
один шаг, рисует поле, спит `1 / скорость` секунды и вызывает `st.rerun()` —
и так по кругу, пока включён флаг `running`. Каждый перезапуск даёт Streamlit
шанс обработать нажатие «Пауза», поэтому управление не залипает.

**Отрисовка** — Pillow: массив цветов растягивается через `np.repeat`
и при размере клетки от 6 пикселей разлиновывается сеткой.

**Состояние** живёт в `st.session_state`: поле, поколение, история популяции,
правило и флаг запуска. Кнопка «Сброс» очищает состояние целиком.

## Проверки

```bash
python test_life_core.py       # 24 проверки: математика автомата
python test_streamlit_ui.py    # 20 проверок: интерфейс, Streamlit не нужен
python test_app_streamlit.py   # проверка в настоящем Streamlit (AppTest)
```

Все три файла работают и без pytest, и через него:

```bash
pytest -q
```

Что покрыто:

- **Логика.** Блок неподвижен, мигалка имеет период 2, планер за 4 поколения
  смещается на (1, 1), LWSS — на две клетки влево, пушка Госпера растёт,
  `B36/S23` отличается от `B3/S23`, различаются тор и мёртвая граница,
  корректны обрезка и заворот фигур, ловятся неверные правила и пустые узоры.
- **Интерфейс.** Заглушка подменяет модуль `streamlit`, а скрипт выполняется
  через `runpy` — так же, как его запускает сам Streamlit. Проверяются все
  кнопки, смена правила, изменение размера поля (старые клетки переезжают
  в левый верхний угол), автозапуск, пауза между кадрами, обрезка истории
  и обработка ошибок ввода.
- **End-to-end.** `test_app_streamlit.py` поднимает приложение штатным
  `streamlit.testing.v1.AppTest` и проверяет состояние сессии после нажатий.

## Ограничения

- `test_streamlit_ui.py` — это заглушка API, а не настоящий Streamlit: она
  проверяет логику интерфейса, но не вёрстку. Настоящая проверка — в
  `test_app_streamlit.py`, она требует установленного Streamlit. В CI она
  вынесена отдельной необязательной задачей.
- Клетки нельзя переключать мышью по полю: для этого нужен
  `streamlit-drawable-canvas`. Вместо этого есть готовые фигуры и вставка
  собственного узора ASCII-картинкой.
- История популяции ограничена 600 записями, чтобы график не разрастался.
